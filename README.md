# Legends Nudge Bridge

Future Pinball's **Digital Nudge Left / Right / Up** fields only accept *keyboard*
keys. You cannot bind a gamepad button to them — FP's controller section covers
flippers, start, coin and so on, but nudge is keyboard-only, and the analog nudge
fields want axes, not buttons.

So if you want the **physical nudge buttons** on an AtGames Legends cabinet
(4KP / Pinball / Ultimate, running in OTG controller mode) to nudge in Future
Pinball, something has to turn those buttons into keystrokes.

This is that something — a single 74 KB tray app, no installer, no dependencies,
no general-purpose remapping UI to fight with.

```
Legends Nudge Bridge  —  tray

  Nudge Left      VID_XXXX/PID_XXXX  button 5   ->  Z
  Nudge Right     VID_XXXX/PID_XXXX  button 12  ->  SLASH
  Nudge Forward   VID_XXXX/PID_XXXX  button 2   ->  SPACE

  keys sent only while Future Pinball is in the foreground
```

## Why not JoyToKey

Same idea, but this one binds *only* the buttons you point at, leaves every other
control on the cabinet untouched, holds the key for exactly as long as you hold
the button, and releases everything the moment FP loses focus.

## Requirements

- Windows 10 or 11, 64-bit
- The cabinet connected in **OTG → Controller Type → Gamepad/Controller** mode.
  In *Keyboard* OTG mode the buttons are already keystrokes and Windows never
  sees them as a gamepad, so this app has nothing to read.

## First run

1. Put `LegendsNudge.exe` in a normal folder — `Documents\LegendsNudge\` is fine.
   Avoid `Program Files`; it needs to write `nudge.ini` next to itself.
2. Double-click it. Windows SmartScreen will warn you, because the exe isn't code
   signed (signing costs a few hundred dollars a year). *More info → Run anyway*.
3. It starts with nothing bound and opens **Setup**.
4. Click **Bind** next to *Nudge Left*, then press the left nudge button on the
   cabinet. It captures the device and button number. Repeat for right and
   forward. Click **Save**.
5. The app now lives in the system tray. Right-click it for Setup, Diagnostics
   and the rest.

Nothing about the button numbers is hardcoded — they vary between models and
firmware revisions, so the app learns them from your cabinet, and stores them
against the device's USB VID/PID so they survive a replug or reboot.

Note that Legends cabinets often expose **more than one** input device to
Windows. That's handled: every binding remembers which device it came from, so
it's fine if left nudge lives on one device and forward nudge on another.

## The Future Pinball side

Open Future Pinball (the editor/launcher itself, not a table) →
**Preferences → Game Keys and Controls**, and look at the Digital Nudge keys.
The stock assignments are:

| Action        | Default FP key |
| ------------- | -------------- |
| Nudge Left    | `Z`            |
| Nudge Right   | `/`            |
| Nudge Forward | `Space`        |

Whatever FP has there is what you type into the **key** column in Setup. The
defaults already match the table above.

If `/` misbehaves, the quickest fix is to change FP's own Nudge Right to
something unambiguous like `X` or `F5` and set the same here — `/` is one of the
few keys whose scancode is genuinely layout-dependent.

## Hold vs pulse

By default the key is held for exactly as long as you hold the button, which is
what you want if FP's nudge is edge-triggered.

If holding a nudge button makes FP nudge repeatedly and tilt too easily, open
`nudge.ini` and set:

```ini
[options]
mode     = pulse
pulse_ms = 60
```

That taps the key once per press instead. It's a config change, not a rebuild.

## The foreground gate

Keys are only injected while one of these is the active window:

```ini
only_when = Future Pinball.exe, FPLoader.exe, BAM.exe
```

so the app can't type `Z` into your browser. If nudge does nothing, this is the
first thing to check: open **Diagnostics** from the tray, look at
`Foreground app`, and if the exe name isn't in the list, add it. Set
`only_when = always` to disable the gate entirely.

## Diagnostics

Right-click tray → **Diagnostics** (or double-click the tray icon). It shows,
live at ~16 Hz:

- whether keys are allowed right now, and the current foreground exe
- every binding, its device, its button, its key, and whether it's pressed
- every connected joystick, its name, VID/PID, and which button numbers are down

That last section is also the quickest way to find a button number without
using Setup — just press it and read the list.

## nudge.ini

Written next to the exe, regenerated by Setup, safe to hand-edit
(tray → *Reload config* to pick up changes).

```ini
[binding.left]
label  = Nudge Left
vid    = 0x1234        ; USB vendor id of the device the button is on
pid    = 0x5678        ; USB product id
button = 5             ; 1-based, as shown in Diagnostics
key    = Z

[binding.right]
...
[binding.forward]
...

[options]
mode      = hold       ; hold | pulse
pulse_ms  = 60
only_when = Future Pinball.exe, FPLoader.exe, BAM.exe
poll_ms   = 2          ; 1-50
log       = 0          ; 1 writes nudge-log.txt next to the exe
```

You can add extra bindings beyond the three — any `[binding.<name>]` section
works, up to eight total.

### Key names

`A`–`Z`, `0`–`9`, `F1`–`F12`, `SPACE`, `ENTER`, `TAB`, `ESC`, `BACKSPACE`,
`LSHIFT`, `RSHIFT`, `LCTRL`, `RCTRL`, `LALT`, `RALT`,
`COMMA`, `PERIOD`, `SLASH` (`/`), `SEMICOLON`, `APOSTROPHE`, `LBRACKET`,
`RBRACKET`, `BACKSLASH`, `MINUS`, `EQUALS`, `GRAVE`,
`UP`, `DOWN`, `LEFT`, `RIGHT`, `HOME`, `END`, `PGUP`, `PGDN`, `INSERT`,
`DELETE`, `NUMPAD0`–`NUMPAD9`, `NUMPADSLASH`, `NUMPADENTER`, `CAPSLOCK`.

Punctuation may be written literally (`/`, `,`, `.`) and a raw scancode works
too (`0x35`).

## Troubleshooting

**No joysticks detected** — the cabinet is in Keyboard OTG mode, or not
connected. Diagnostics says so explicitly.

**Buttons show in Diagnostics but nudge does nothing in FP** — check
`Keys allowed now`. If it says no, the foreground exe isn't in `only_when`.

**Nudge fires but FP tilts instantly** — switch to `mode = pulse`.

**A key got stuck** — it shouldn't; keys are released on focus loss, on disable,
on unplug, on shutdown and on exit. If it ever happens, tap the key on a real
keyboard and please note what you were doing.

**Bindings stopped working after a firmware update** — the VID/PID or button
numbering may have changed. Re-run Setup; it takes fifteen seconds.

## How it works

- Buttons are read with the winmm joystick API (`joyGetPosEx`), polled every
  2 ms with `timeBeginPeriod(1)` so the poll actually runs at 2 ms rather than
  the default ~15 ms timer granularity.
- Keys are injected with `SendInput` using **hardware scancodes**
  (`KEYEVENTF_SCANCODE`), which is what DirectInput-era games like Future
  Pinball read. Virtual-key injection is less reliable with them.
- Setup and the runtime read buttons through the same API, so the number you
  bind is by construction the number that gets matched — no translating between
  DirectInput, XInput and raw HID numbering.

## Building

Cross-compiled from macOS or Linux with mingw-w64:

```sh
brew install mingw-w64     # macOS
./build.sh                 # -> dist/LegendsNudge.exe
```

Single C file, no third-party dependencies, statically linked.
